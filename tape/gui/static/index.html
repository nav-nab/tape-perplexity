Tape generator

Pick or build a starting sequence of trade events. The trained model then continues it, one event at a time, by sampling each next token from its predicted distribution. Each token is drawn as an icon: colour is the side (blue buy, orange sell), dot size is the order size, and the tail shows the price move.
